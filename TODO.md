# UWC — дорожная карта

> **Useless Whatever Converter** — «конвертер всего во что угодно». Цель: поддержать не только популярные форматы (JPEG/PNG, JSON/CSV), но и «бесполезные» (QR, vCard, iCal, GeoJSON, транслит, SQL, base64…), при этом не разориться на RAM/CPU.

> **Как читать этот файл.** Раздел 0 — что реально сделано (сверено с кодом и тестами, август 2026). Разделы 1–7 — роадмап по **трекам** (направлениям работ), внутри трека — эшелоны по цене. Исторические решения и «грабли» — в разделах 8–9, бэклог идей — в разделе 10.
>
> **Нишевые форматы «для 1%»** (кодировки, шифры, практичные мелочи, генераторы) вынесены в отдельный **[ADD_FORMATS.md](ADD_FORMATS.md)** — чтобы не раздувать основной роадмап.
>
> **Мини-проект «Reddit → официальное письмо»** (сатира + невидимая вотермарка + экспорт в PNG) — в отдельном **[LETTERS.md](LETTERS.md)**.

### Ключевые архитектурные решения (работают в проде)

- **IR-звезда для данных** (`shared/registry/ir.ts`): формат = `parse → IrNode` / `serialize(IR)`, N² пар ценой 2N модулей. Тир — свойство формата, а не пары.
- **PNG/RGBA-хаб для изображений**: новый формат = один модуль-адаптер, пары генерятся из источников × целей.
- **PCM-хаб для аудио**: вход всегда декодируется Web Audio в PCM, выход — `@audio/encode`.
- **Client-first**: всё, что умеет браузер, не трогает сервер; сервер — fallback с цветовой индикацией (зелёный/красный бейдж).

## 1. Трек «Архивы» 🟡 ядро готово

Вход (распаковка) — вкладка в студии, всё в браузере. Выход (создание) — отложено в фазу «пакетная обработка».

### Готово ✅

- [x] **ZIP** — `fflate` (unzipSync), список + скачивание отдельных файлов
- [x] **TAR** — рукописный ustar-парсер (512-байтовые блоки, префикс путей, паддинг, checksum)
- [x] **TAR.GZ / .tgz** — `fflate.gunzipSync` + tar-парсер
- [x] **GZIP (.gz)** — одиночный файл, имя без суффикса
- [x] **Brotli (.br)** — нативный `DecompressionStream` ('br' в браузерах / 'brotli' в Node), 0 зависимостей
- [x] Детект формата по магическим байтам, бейдж формата в UI, accept в дропзоне
- [x] Тесты: tar-билдер в памяти, round-trip TAR → TAR.GZ → распаковка, brotli round-trip (13 тестов)

### Дальше по треку

- [ ] **Безопасность распаковки**: лимит суммарного распакованного размера (zip-бомба), лимит числа записей, path traversal в TAR (нормализация путей перед выдачей) — **приоритет трека**
- [ ] **LZMA (.lzma / .tar.lz)** — ⚠️ fflate НЕ умеет LZMA (только DEFLATE-семейство) — брать `lzma-js` (MIT) или порт руками — день
- [ ] **BZIP2 (.bz2 / .tar.bz2)** — чистый JS-декодер (порт) — день
- [ ] **ZSTD (.zst / .tar.zst)** — WASM (`zstd-codec`) — день
- [ ] **XZ (.tar.xz)** — WASM (`xz-wasm`) — день
- [ ] **7z / RAR** — WASM, только чтение — по спросу, 2 дня
- [ ] **CAB** — реально руками, см. решение ниже: контейнер ~150–200 строк + **MSZIP = raw-deflate через `fflate.inflateRaw`** (~50 строк, покрывает большинство реальных файлов) → уровень A, в браузере, 0 зависимостей. LZX (+1–2 дня, ~500 строк, портировать) и Quantum — второй эшелон / не брать. libmspack не используем (LGPL). Бонус-сценарий: CAB внутри MSU-обновлений Windows
- [ ] **ACE** — не берём: единственная реализация (`unace`) под ограничительной лицензией + CVE-2018-20250 в unacev2 + формат мёртв. Вместо поддержки — **детект по магии + понятное сообщение** («ACE не поддерживается, распакуйте в ZIP»)
- [ ] ~~CAB через libmspack~~, ~~ACE через unace-wasm~~ — лицензии (LGPL / restrictive) и багаж
- [ ] **Выход (создание архивов)**: ZIP/TAR/TAR.GZ руками через fflate `zipSync` — вместе с пакетной обработкой

### Дальний бэклог — «список 7-Zip» (неосновные форматы, по спросу)

Сгруппировано по типу работы: кодеки сжатия / архив-контейнеры / образы ФС и дисков. Образы ФС — комбинаторика (контейнер × ФС × кодек), самый дорогой класс.

**Тир 1 — чистый JS, в браузере, дёшево (суммарно ~2–3 дня, лучший ROI — выделяет среди конкурентов):**
- [ ] **CPIO** — контейнер ~150 строк — вечер; ключ к RPM и initramfs
- [ ] **AR (.a/.deb)** — ~80 строк — вечер; **DEB = AR + TAR почти бесплатно** 🎁
- [ ] **Z (.Z)** — LZW-декодер ~100 строк — вечер
- [ ] **ISO (ISO9660)** — ~250 строк, самый востребованный из списка — день
- [ ] **XAR** — контейнер с чексуммами — день
- [ ] **IHEX** — текстовый, час; скорее конвертер, чем архив
- [ ] **GPT/MBR** — таблицы разделов, вечер каждая; без ФС-парсера внутри малополезны

**Тир 2 — день-два, кодек из либы/WASM:**
- [ ] **RPM** = AR + CPIO (gzip/zstd внутри) — день при готовом cpio
- [ ] **MSI** = CFB-контейнер (`cfb`, MIT) + встроенные CAB — день-два
- [ ] **CHM** = контейнер + LZX — день-два
- [ ] **WIM** = контейнер + Xpress/LZX/LZMS — 2–3 дня, нишевый
- [ ] **SquashFS** — superblock + zlib/lzma/xz/zstd — 2 дня, живой (Linux-образы)
- [ ] **LZH** — LZW+Huffman — день; **ARJ** — мёртвый, либ нет

**Тир 3 — дорого/нишевое (не берём без запроса через UWC+):**
- [ ] DMG (2–3 дня: UDIF + HFS+), FAT (день-два), NTFS/EXT/HFS+ (неделя+ каждый)
- [ ] VDI/VHD/VHDX/VMDK/QCOW2 — контейнеры дёшевы, но нужна ФС внутри — комбинаторика
- [ ] NSIS (реверс-инжиниренный, зависит от версии), CramFS, UDF, UEFI, APFS (неполные спеки)

## 8. Решения по открытым вопросам (август 2026)

- [x] **Медиа / ffmpeg** → видео отложено «на потом когда-то». Аудио полностью в браузере без ffmpeg: декод — нативный Web Audio (`decodeAudioData`), WAV — руками (PCM 16-bit), MP3 — `@breezystack/lamejs`, остальные — `@audio/encode` (PCM-хаб, `app/utils/audioConvert.ts`). ffmpeg-static — опция только для видео.
- [x] **Деплой** → VPS без Docker, Caddy / PM2, рантайм Node (sharp нативный), edge — нет. Уровни A и часть B — можно на edge.
- [x] **Прогресс/очередь** → синхронный ответ — дефолт. Серверу — простой семафор + лимиты; BullMQ+Redis не нужен.
- [x] **Студия на отдельной странице** → `/converter` отдельная страница, лендинг переиспользует компонент. Продвинутые фичи — туда.
- [x] **Иконки** → `@nuxt/icon` по умолчанию не бандлит иконки из `.ts`-реестров; лечится `icon.clientBundle.scan` с `globInclude` по `.ts` в `nuxt.config.ts`.
- [x] **Расширение форматов изображений** → ImageMagick отклонён (спавн процессов, CVE, delegates). PNG/RGBA-хуб: новый формат = один адаптер, пары генерятся из источников × целей. Честный потолок без ImageMagick — ~30–40 форматов, это 99% спроса; экзотика — через UWC+ (раздел 10).
- [x] **Архитектура уровня B → IR-звезда** → `IrNode` (JSON-совместимый + Date), формат = parse/serialize, пара = `makePair`. Либы заперты за интерфейсом. Тир — свойство формата: конвертер клиентский ⇔ оба модуля умеют в браузер (`DOMParser`/`CompressionStream`/`deflate-raw` покрывают XML/ZIP/gzip).
- [x] **Graceful degradation: capability detection вместо UA-сниффинга** → модуль проб `shared/registry/capabilities.ts` + `useCapabilities()` (кэш на сессию). Пробы: canvas (`toBlob` по целевому MIME), Web Audio (реальный `decodeAudioData`), WebCodecs (`isConfigSupported`), `CompressionStream`/`DecompressionStream`. Роутинг — `resolveRoute(from, to, caps) → 'client' | 'server' | 'degrade'`; `degrade` — отдельное состояние UI с действием («скачать оригинал»), не красный текст. Каскады: canvas → сервер → degrade; клиентский фолбэк при недоступности сервера.

## 9. Технические грабли (запомнить на будущее)

- **Nuxt UI v4 требует `<UApp>`** в app.vue — без него падает `UTooltip` («Injection not found: TooltipProvider»).
- **Группировка `USelect`** — массив массивов `T[][]`, заголовок группы — `{ type: 'label' }`.
- **Иконки**: `@iconify-json/*` бандлятся локально; `icon: { mode: 'svg' }`. Без `clientBundle.scan` иконки из реестров (`.ts` сканер не читает) тянутся рантаймом через `/api/_nuxt_icon` — лечится `globInclude` в `nuxt.config.ts`.
- **Контраст**: лайм + `text-inverted` → `text-black` у solid-кнопок (`app.config.ts` → `compoundVariants`), иначе WCAG в светлой теме.
- **Автоимпорт новых компонентов** в dev иногда требует рестарта.
- **i18n**: реестры в `shared/` языконезависимы — строки только в `i18n/locales/*.json`; ошибки из shared — ключи, `t(message)` на месте вызова. `no_prefix` + `detectBrowserLanguage: false`, кука `uwc_locale` пишется вручную (app.vue и error.vue).
- **vue-i18n**: `@` в начале строки ломает парсер — экранировать `{'@'}`. Плюралы — pipe-синтаксис работает, но для счётчиков в компонентах надёжнее `Intl.PluralRules`.
- **Локализация вывода**: конвертер «Статистика» использует `runL(input, t)`.
- **fflate 0.8.3 не умеет Brotli** — только нативный `DecompressionStream`; имя формата различается: браузеры `'br'`, Node.js `'brotli'`.
- **Brotli-детект**: магии нет; канонический WBITS-байт (`0x21/0x81/0x91/0xa1/0xe1/0x3b`) + raw-заголовок (младший полубайт `0xb`, так кодирует Node).
- **`Buffer` в Nitro**: библиотеки вроде mammoth требуют `Buffer.from(input)` явно; в тестах — `Uint8Array`.
- **pdfjs-dist** — только legacy-билд (`pdfjs-dist/legacy/build/pdf.mjs`), браузерный требует DOMMatrix.
